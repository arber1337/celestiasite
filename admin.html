Lidhni llogarinë GitHub

Publikimi lejohet vetëm për pronarin e arber1337/celestiasite. Kodi përdoret vetëm në këtë sesion dhe nuk ruhet në website ose në pajisje.

Si të krijoni kodin e lidhjes — vetëm herën e parë
  1. Në GitHub hapni Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Zgjidhni llogarinë arber1337, vendosni një afat skadence dhe aktivizoni vetëm repository celestiasite.
  3. Te Repository permissions vendosni Contents: Read and write. Metadata lejohet automatikisht. Nuk nevojiten leje për repository të tjera.
  4. Kopjoni token-in dhe vendoseni këtu. Mos e dërgoni në chat dhe mos e shtoni si skedar në repository.
